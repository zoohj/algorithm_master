## boj 10814번 문제
https://www.acmicpc.net/problem/10814

```
import sys

members = int(sys.stdin.readline()) # 총 몇명을 인풋받는지 확인
mem_lst = []

# 가입자의 나이와 이름을 딕셔너리 형태로 리스트 안에 저장
for i in range(members):
    age, name = sys.stdin.readline().split()
    user_info = {'age': int(age), 'name': name}
    mem_lst.append(user_info)

# 나이순으로 정렬
mem_lst.sort(key=lambda x: x['age'])

for info in mem_lst:
    print(info['age'], info['name'])
```
