## boj 2839번 문제
https://www.acmicpc.net/problem/2839

```
num = int(input()) # 값을 input 받음
count_num = 0 # 갯수를 새기 위한 변수

# num이 0 이하가 될 때까지 반복
while num > 0:
    # 5로 나누어질 경우 5로 나눈 몫만큼 횟수를 더함
    if num % 5 == 0:
        count_num += num // 5
        num = num % 5
    else:
        # 5로 나누어지지 않는다면 num에서 3씩 빼고 횟수를 한번씩 더함
        num -= 3
        count_num += 1
    
    # num이 0 이하가 되면 while문 탈출
    if num < 0:
        break

# 만약 5와 3으로 나눠도 0이 되지 않는다면 -1 출력
if num % 5 or num % 3 != 0:
    print(-1)
else:
    # 그렇지 않다면 총 몇개를 배달해야하는지 출력
    print(count_num)
```
