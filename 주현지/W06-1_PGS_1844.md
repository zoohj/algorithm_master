## [BFS] 프로그래머스 - 1844. 게임 맵 최단거리
> **핵심 키워드:** *#BFS #최단거리 #격자탐색 #Queue*

https://school.programmers.co.kr/learn/courses/30/lessons/1844


### 1. 💡 핵심
* > **"최단 거리는 BFS! `maps`를 직접 거리판으로 쓰면 메모리도 아끼고 방문 체크도 한 번에 해결"**
* "**최단 거리**"를 묻는 문제이며, 각 칸의 이동 비용(가중치)이 동일함 $\rightarrow$ **BFS**
* DFS는 모든 경로를 다 가봐야 최단을 확신할 수 있지만, **BFS는 처음 도착지에 닿는 순간이 무조건 최단**임.
  
---


### 2. 주의 사항

* **변수명 주의:** 변수명을 `map`으로 지으면 파이썬 내장 함수와 충돌하여 `TypeError` 발생.
* **인덱스 범위:** $n \times m$ 크기 맵의 도착지는 `[n][m]`이 아니라 **`[n-1][m-1]`**.
* **방향 탐색 조건:** `nx, ny` 계산 후 
  * **① 범위 체크**(`0 <= nx < n ...`)를 
  * **② 방문 체크**(`maps[nx][ny] == 1`)보다 먼저 해야 `IndexError`를 피할 수 있음.
* **예외 처리:** 목적지에 도달할 수 없을 때 `-1`을 반환.
* **최소 메모리 사용:** 따로 방문 체크 배열을 만들지 말고 원본 maps 배열을 업데이트
* **BFS 종료 조건 설정**: 큐가 빌 때까지
* **코드 가독성:** 왜 += 대신 +1인가? BFS의 정석은 현재 거리(dist)에 1을 더하는 것이며, 코드의 의도가 훨씬 명확해짐.

---


### 4. 코드 설계 흐름
1. **준비:** `deque`, 방향 벡터(`dx`, `dy`), 큐 초기화.
2. **반복:** `while queue:` -> `popleft()` -> `4방향 탐색`.
3. **조건:** `범위 안인가?` AND `처음 가는 길(1)인가?`.
4. **결과:** 마지막 칸이 1보다 크면 그 값 반환, 아니면 -1.

---


### 5. ☁️ 최종 정답 코드

```python

from collections import deque

def solution(maps):
    # 맵 크기 정의
    n=len(maps)
    m=len(maps[0])

    # 방향 벡터 (상, 하, 좌, 우)
    dx=[-1,1,0,0]
    dy=[0,0,-1,1]    

    # 1. que에 시작좌표(0,0) 넣기 (for BFS)
    queue = deque([(0,0)])
    
    while queue:
        x,y=queue.popleft()
        
        for i in range(4):
            # 2. que에서 좌표 하나 꺼내 상하좌우 살핌(dx,dy)
            nx = x+dx[i]
            ny=y+dy[i]
            # 배열 인덱스 에러 방지
            if 0 <= nx < n and 0 <= ny < m:
                # 3. ⭐️ 범위 안, 아직 방문하지 않은 길(1)인 경우만 한칸 이동
                # 1을 넘는다면 이미 더 빠른 길로 누군가가 왔다는 의미이므로 pass
                if maps[nx][ny]==1:
                    maps[nx][ny] =maps[x][y] +1 # 한칸 이동
                    # 4. 이동 후, 좌표를 다시 큐에 넣음(살펴봐야하는 좌표 저장)
                    queue.append((nx,ny))
        # 5. 큐가 빌때까지 반복 
                    
    # 목적지의좌표(n,m)에 들어있는 값이 최소값(인덱스 주의)
    answer = maps[n-1][m-1]
    
    return answer if answer > 1 else -1

```
