### 1. 💡 핵심

* > **"매번 최솟값 두 개를 꺼내 섞어야 한다면? 정렬(Sort) 대신 힙(Heap)"**


* **최솟값 유지:** 데이터를 넣을 때마다 자동으로 가장 작은 값이 맨 앞에 오도록 유지.
* **효율성:** 일반 리스트에서 `min()`이나 `sort()`를 반복하면 $O(N^2)$이 되어 시간 초과가 발생하지만, **Heap**을 사용하면 삽입과 삭제 모두 $O(\log N)$에 해결 가능.

---

### 2. 주의 사항

* **데이터 크기:** `scoville`의 길이가 최대 1,000,000이므로 효율적인 자료구조 선택이 필수.
* **루프 종료 조건:** 힙의 최솟값(`scoville[0]`)이 $K$ 이상이 되는 순간 즉시 종료.
* **예외 처리:** 모든 음식을 섞었는데도 마지막 남은 음식의 지수가 $K$ 미만이라면 `-1`을 반환. (큐에 원소가 2개 미만일 때 체크)
* **heapify 사용:** 빈 힙에 하나씩 `heappush` 하는 것보다 기존 리스트를 `heapify` 하는 것이 더 빠름 ($O(N)$).
* **Python의 `heapq`**
  * 항상 **0번 인덱스(`heap[0]`)**에 최솟값이 위치함을 보장
  * 하지만 `heap[1]`이 두 번째로 작은 값이라는 보장은 없음 => 반드시 `heappop()`을 두 번 호출해서 확실하게 가장 작은 두 값을 가져와야 함


#### +@
* **최소 힙(Min-Heap)**: 부모 노드가 자식 노드보다 항상 작은 완전 이진 트리.
* **Dijkstra 알고리즘**: 최단 경로를 찾는 알고리즘에서도 가장 가까운 노드를 찾기 위해 `heapq`가 필수적으로 사용됨.

---

### 3. 코드 설계 흐름

1. **힙 변환:** `heapq.heapify(scoville)`를 통해 리스트를 최소 힙 구조로 만듦.
2. **반복:** `while scoville[0] < K:` (가장 안 매운 음식이 기준 미달인 동안)
3. **체크:** 남은 음식이 2개 미만이면 더 이상 섞을 수 없으므로 `-1` 반환.
4. **섞기:** `heappop`으로 가장 작은 값(`first`)과 두 번째 값(`second`)을 꺼내 공식 적용 후 다시 `heappush`.
5. **결과:** 루프 종료 시점의 `answer` 반환.

---

### 4. ☁️ 최종 정답 코드

```python
import heapq

def solution(scoville, K):
    answer = 0
    # 1. 기존 리스트를 최소 힙(Min-Heap) 구조로 변환
    heapq.heapify(scoville)
    
    # 2. 힙의 최솟값(0번 인덱스)이 K보다 작은 동안 반복
    while scoville[0] < K:
        # 3. 섞기 위해 최소 2개의 음식이 있는지 확인
        if len(scoville) < 2:
            return -1
        
        # 4. 가장 작은 두 음식을 꺼내서 섞기
        # heappop은 항상 가장 작은 값을 내보내고 힙을 재구조화
        first = heapq.heappop(scoville)
        second = heapq.heappop(scoville)
        
        mixed = first + (second * 2)
        heapq.heappush(scoville, mixed)
        
        answer += 1
        
    return answer

```
