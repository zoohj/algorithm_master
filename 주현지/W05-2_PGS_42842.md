## [완전탐색] 프로그래머스 - 42842. 카펫

> **핵심 키워드:** *#완전탐색 #BruteForce #수학 #약수찾기*

https://school.programmers.co.kr/learn/courses/30/lessons/42842

### 1. 💡 핵심

* > **"전체 격자(Total)의 가로($x$)와 세로($y$)는 'Total의 약수' 관계이며, 테두리 한 줄은 갈색이다."**


* **수학적 모델링:** 가로가 $x$, 세로가 $y$일 때, 갈색 테두리의 개수는 $2x + 2y - 4$. (모서리 겹침 4개 제외)
* **탐색 범위 효율화:** 전형적인 완전탐색 문제이지만, 모든 경우의 수를 따지는 대신 total의 약수를 찾는 방식으로 범위를 좁히는 것이 포인트.

---

### 2. 주의 사항

* **세로($y$)의 최소값:** 노란색 격자가 최소 1개라도 존재하려면, 카펫의 세로 길이는 **최소 3** 이상이어야 함. (위 테두리 + 노란색 + 아래 테두리)
* **반복 범위 최적화:** $x \ge y$ 조건에 따라 세로 $y$는 `total`의 **제곱근**까지만 확인하면 충분($O(\sqrt{N})$).
* **수식 검증:** `2 * (x + y) - 4 == brown` 로 검증 로직을 구현.
* **나누어떨어짐 확인:** $x = total // y$를 수행하기 전, `total % y == 0`인 약수 관계인지 반드시 먼저 확인.
* **문법실수 주의:** 파이썬에서는 곱셈 기호를 생략할 수 없으므로 `2(x+y)`가 아닌 `2 * (x + y)`로 작성


---

### 3. 코드 설계 흐름

1. **전체 넓이 계산:** `total = brown + yellow`
2. **세로 길이($y$) 탐색:** 3부터 `int(total**0.5)`까지 반복.
3. **가로 길이($x$) 도출:** `total % y == 0`일 때, `x = total // y`.
4. **조건 검사:** $x$와 $y$에서 각각 2를 뺀 값의 곱이 `yellow`와 같은지 확인.
5. **결과:** 조건을 만족하는 첫 번째 `[x, y]`를 반환.

---

### 4. ☁️ 최종 정답 코드

```python
import math

def solution(brown, yellow):

    # 1. 전체 격자 수 계산
    total = brown + yellow
    answer = []

    # 2. 세로(y)는 최소 3부터 전체 넓이의 제곱근까지 탐색
    # 가로(x) >= 세로(y) 조건
    for y in range(3, int(math.sqrt(total)) + 1):
        # 3. total의 약수인 경우만 체크
        if total % y == 0:
            x = total // y  # 가로 길이 계산
            
            # 4. ⭐️ 수식 검증 
            # brown = 2*(가로+세로-1)-2 = 2(가로+세로)-4
            if 2*(x+y)-4 == brown:
                answer = [x, y]
                break
                
    return answer

```
