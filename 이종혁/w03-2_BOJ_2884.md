# 오늘의 알고리즘 (2026-02-08)

## 2. 문제 정보
- 번호: 2884
- 제목: 알람 시계
- 문제: 주어진 상근이의 알람 시간을 45분 앞서는 시간으로 설정하기
- 링크: https://www.acmicpc.net/problem/2884
- 난이도: Bronze 3

## 3. 내 풀이
```python
a, b = map(int, input().split())

if b < 45 and a > 0:
    # 45분보다 작고 시간이 0보다 클 때 (시간을 1 줄이고 분에 60분을 빌려옴)
    a -= 1
    b += 15  # b + 60 - 45와 동일함
    print(a, b)
elif b >= 45:
    # 분이 충분할 때는 분만 45 차감
    b -= 45
    print(a, b)
else:
    # b < 45이면서 a가 0인 경우 (전날 23시로 이동)
    a = 23
    b += 15
    print(a, b)
```

## 4. 항목별 설명
- **문제 풀이(사고의 전환 등)**: 
    - 처음에는 단순히 45를 빼는 것만 생각했으나, '분'이 부족할 때 '시간'에서 60분을 빌려와야 하는 **내림 계산**이 핵심임을 파악함.
    - 특히 0시에서 시간이 줄어들 때 23시로 넘어가는 **경계값 조건**을 처리하기 위해 조건문을 세분화함.
- **배운 점(기술적 정리)**: 
    - `b + 60 - 45`를 `b + 15`로 단순화하여 연산 효율을 높이는 법을 익힘.
    - `if-elif-else` 구조를 통해 모든 경우의 수(분 부족/충분, 0시 여부)를 빠짐없이 체크하는 법을 배움.

## 5. 덧붙임: 피드백
- `a += 23`보다는 `a = 23`처럼 명시적인 할당을 사용하는 것이 코드의 의도를 전달하는 데 더 명확함.
- 경계값(45분 정각, 0시 정각 등)을 테스트 케이스로 항상 고려하는 습관을 들일 것.
