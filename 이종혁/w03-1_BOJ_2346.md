# 오늘의 알고리즘 (2026-02-08)

### 1. 문제 정보
* **번호**: 2346
* **제목**: 풍선 터뜨리기
* **문제**: 원형으로 놓인 풍선을 터뜨리고, 나온 숫자만큼 이동하며 다음 풍선을 터뜨리는 과정을 반복하여 터진 풍선의 번호를 순서대로 출력하는 문제.
* **링크**: [https://www.acmicpc.net/problem/2346]
* **난이도**: 실버 3

### 2. 내 풀이
```python
# 1. 풍선 개수 입력
n = int(input())

# 2. (풍선 번호, 적힌 숫자) 형태로 리스트 만들기
# enumerate를 사용해 1번부터 번호를 매겨서 관리함
balloons = list(enumerate(map(int, input().split()), start=1))

# 3. 현재 위치 인덱스 초기화
idx = 0

for _ in range(n):
    # 현재 위치의 풍선을 리스트에서 꺼내고 삭제함 (pop)
    now = balloons.pop(idx)
    # 풍선 번호(now[0]) 출력
    print(now[0], end=' ')
    
    # 풍선이 더 이상 남아있지 않으면 이동 계산 중단
    if not balloons:
        break
    
    # 풍선 안에 적힌 이동할 숫자
    step = now[1] 
    
    # 다음 인덱스 계산
    if step > 0:
        # 양수일 때는 내 자리가 사라지면서 뒷사람들이 당겨졌으므로 -1 보정
        idx = (idx + step - 1) % len(balloons)
    else:
        # 음수일 때는 사라진 자리와 관계없이 뒤로 이동하므로 그대로 계산
        idx = (idx + step) % len(balloons)
```

### 3. 항목별 설명
* **문제 풀이**: 
  - `list`의 `pop()` 메서드를 사용하여 터뜨린 풍선을 제거.
  - 리스트가 비어있지 않을 때만 인덱스를 갱신하도록 하여 `IndexError`를 사용
  - 나머지 연산자(`%`)를 사용하여 인덱스가 리스트의 길이를 벗어나더라도 원형으로 다시 돌아오게 설계
* **배운 점**: 
  - `enumerate`의 `start=1` 옵션이 출력 시 편함.
  - 리스트에서 요소를 삭제했을 때 인덱스가 재조정되는 과정을 직접 계산해보며 인덱스 보정(`-1`)의 필요성을 이해함

### 4. 덧붙임
*리스트만으로도 인덱스의 변화 원리를 정확히 알면 문제를 풀 수 있다는 점. 특히 양수와 음수 이동 시 보정 로직이 다르다는 점이 인상적이다.
