## 문제 주소
* https://www.acmicpc.net/problem/18352

## 문제 설명
* N개의 도시, M개의 단방향 도로가 존재하고, 모든 도로의 거리는 1이다.
* 특정 도시 X로부터 출발하여 도달할 수 있는 모든 도시 중에서, 최단 거리가 정확히 K인 도시들의 번호를 출력하자.

## 풀이 과정
* 하나의 정점에서 모든 정점들의 최단 경로를 구하고 비교하는 문제.
* 다익스트라 알고리즘으로 해결.

## 로직
1. 입력값 받고, 다익스트라 구현.
2. 다익스트라로 출발점에서 모든 도시의 최단 경로를 구한다.
3. 우리가 원하는 최단 거리와 모든 도시의 최단 거리를 비교해서 일치하는 것만 리스트에 저장.
4. 리스트에 저장된 데이터의 개수에 따라 출력하면 끝!

## 코드

```python
# https://www.acmicpc.net/problem/18352
import sys
import heapq
from collections import defaultdict

input = sys.stdin.readline

city_num, edge_num, target_length, start_city = map(int, input().split())

graph = defaultdict(list)

def dijkstra(start_city, city_cnt, graph):
    # dist = 시작점에서 모든 점까지의 최단 경로를 저장할 리스트.
    dist = [float('inf')] * (city_cnt + 1)
    # 시작점에서 시작점까진 당연히 거리가 0!
    dist[start_city] = 0

    # pq에 시작점 저장 (현재 정점까지의 거리, 정점의 번호)
    pq = [(0, start_city)]

    while pq:
        # pq에 있는 현재까지 이동한 거리와 정점 번호를 저장.
        cost, now = heapq.heappop(pq)

        # 현재까지 이동한 거리가 저장된 최단 거리보다 큰 경우 굳이 최단 경로 계산을 할 필요가 없음.
        if cost > dist[now]:
            continue

        # graph[now]는 현재 정점에서 이동 가능한 모든 정점의 번호와 거리가 저장되어 있음.
        # 반복문을 통해 이동 가능한 정점을 하나씩 체크한다.
        for edge_value, next_vortex in graph[now]:
            # 현재까지의 이동 거리 + 다음 정점으로 이동하는 거리를 더함.
            # 이를 통해 시작점 -> 다음 정점까지의 거리를 저장해두고 최소 값과 비교.
            new_cost = cost + edge_value
            # 기록된 최단 경로보다 짧은 경우 갱신하고 pq에 추가.
            if new_cost < dist[next_vortex]:
                dist[next_vortex] = new_cost
                heapq.heappush(pq, (new_cost, next_vortex))

    return dist

# 그래프에 도시 경로 저장
for _ in range(edge_num):
    start, end = map(int, input().split())
    graph[start].append((1, end))

dist = dijkstra(start_city, city_num, graph)
# 최단 거리가 정확히 target_length와 일치하면 리스트에 저장.
result = []
for i in range(1, city_num + 1):
    if dist[i] == target_length:
        result.append(i)

# 리스트에 저장된 도시가 0개면 -1 출력. 1개 이상이면 도시 번호들 출력.
if len(result) == 0:
    print(-1)
else:
    for data in result:
        print(data)

```
