## 문제 주소
* https://www.acmicpc.net/problem/1238

## 문제 설명
* N개의 마을에 각각 한 명의 학생이 산다.
* N명이 한 마을에 모여서 파티를 연다.
* 마을 사이에는 M개의 단방향 도로가 있고, 각각 지나가는 데 걸리는 시간이 다름.
* 각각의 학생은 파티에 참여하기 위해 해당 마을로 가서 다시 집으로 돌아가야 한다.
* 이동하는 경로는 항상 최단 경로로 이동한다.
* N명의 학생 중 오고 가는데 가장 오래 걸리는 학생의 시간을 구하자.

## 풀이 과정
* 단방향 그래프를 통해 다익스트라를 사용해야 한다.
* 집 -> 파티 장소의 경로와 파티 장소 -> 집의 경로가 서로 다르다.
* 다익스트라는 하나의 시작점에서 모든 정점의 최단 경로를 구하는 알고리즘.
* 파티 장소 -> 집의 경우 그냥 그대로 쓰면 되지만, 집 -> 파티의 경우를 구하기 위해선 도로의 방향을 반대로 해줘야 한다.
* 그래서 총 2번의 다익스트라를 사용할 것이다. (집 -> 파티 장소, 파티 장소 -> 집)

## 로직
1. 다익스트라 구현.
2. 입력 값 받고 집 -> 파티, 파티 -> 집의 최단 경로 저장을 위한 리스트 추가.
3. 리스트에 정점과 간선 정보 저장. 파티 -> 집의 경우는 입력에서 주어지는 그대로 넣으면 되고, 집 -> 파티의 경우 시작점과 도착점의 위치를 반대로 해서 저장.
4. 2번 다익스트라 실행하고, 구해진 최단 경로 리스트들을 각각 합쳐서 가장 큰 값을 출력하면 끝!

## 코드

```python
# https://www.acmicpc.net/problem/1238
import sys
import heapq
from collections import defaultdict

def dijkstra(party_vortex, vortex_cnt, graph):
    # dist = 시작점에서 모든 점까지의 최단 경로를 저장할 리스트.
    dist = [float('inf')] * (vortex_cnt + 1)
    # 시작점에서 시작점까진 당연히 거리가 0!
    dist[party_vortex] = 0

    # pq에 시작점 저장 (현재 정점까지의 거리, 정점의 번호)
    pq = [(0, party_vortex)]

    while pq:
        # pq에 있는 현재까지 이동한 거리와 정점 번호를 저장.
        cost, now = heapq.heappop(pq)

        # 현재까지 이동한 거리가 저장된 최단 거리보다 큰 경우 굳이 최단 경로 계산을 할 필요가 없음.
        if cost > dist[now]:
            continue

        # graph[now]는 현재 정점에서 이동 가능한 모든 정점의 번호와 거리가 저장되어 있음.
        # 반복문을 통해 이동 가능한 정점을 하나씩 체크한다.
        for edge_value, next_vortex in graph[now]:
            # 현재까지의 이동 거리 + 다음 정점으로 이동하는 거리를 더함.
            # 이를 통해 시작점 -> 다음 정점까지의 거리를 저장해두고 최소 값과 비교.
            new_cost = cost + edge_value
            # 기록된 최단 경로보다 짧은 경우 갱신하고 pq에 추가.
            if new_cost < dist[next_vortex]:
                dist[next_vortex] = new_cost
                heapq.heappush(pq, (new_cost, next_vortex))

    return dist

input = sys.stdin.readline

# vortex = 1000, edges 10000 start = X
# 도로가 단방향. 

# 입력값 받기.
vortex_cnt, edges_cnt, target_vortex = map(int, input().split())

# 집 -> 파티 위치로 가는 최단 경로 구할 때 사용할 그래프
home_to_party_graph = defaultdict(list)
# 파티 위치 -> 집으로 가는 최단 경로 구할 때 사용할 그래프
party_to_home_graph = defaultdict(list)

for _ in range(edges_cnt):
    start, end, value = map(int, input().split())
    party_to_home_graph[start].append((value, end))
    home_to_party_graph[end].append((value, start))

home_to_party_dist = dijkstra(target_vortex, vortex_cnt, home_to_party_graph)
party_to_home_dist = dijkstra(target_vortex, vortex_cnt, party_to_home_graph)

max_len = 0

# 집 -> 파티 + 파티 -> 집의 경로 길이가 가장 큰 값을 구한다.
for i in range(1, vortex_cnt + 1):
    max_len = max(max_len, home_to_party_dist[i] + party_to_home_dist[i])

print(max_len)

```
