## 문제 주소
* https://www.acmicpc.net/problem/1107

## 문제 설명
* 리모컨과 보고 싶은 채널이 있는데, 리모콘의 특정 숫자 버튼이 고장난 상태.
* 원하는 채널로 이동하기 위해 몇 번의 버튼 클릭이 필요한지 구하시오.
* 시작 채널은 100번. 주어지는 보고 싶은 채널의 범위는 0 ~ 500,000
* 단, 채널은 무한대 만큼 있음.

## 배운 내용
* python에서 for ~ else 문에 대해 배웠음.
* for ~ else는 for문이 정상적으로 종료되었을 때 else 구문이 실행된다.
* break 등으로 for문이 비정상적으로 종료된 경우에는 else 구문은 무시함.

## 풀이 과정
* 처음에는 채널의 맨 왼쪽 숫자부터 하나씩 구해볼까? 싶었지만, 고려해야 하는 부분이 많은 것 같아서 가장 단순한 방식인 완전 탐색부터 시험해봄.
* 가장 단순하게 반복문과 조건문을 활용해서 가능한 모든 방법을 다 시험하는 방식.
* 3자리의 자물쇠를 풀어야 할 때, 000부터 999까지 다 입력하는 식으로 해결하는 방법이다.
* 문제에 사용할 적당한 알고리즘이 떠오르지 않으면, 그냥 완전 탐색 방식으로 풀어보는 것도 좋음!
* 단, 문제의 수가 적당해야 함. 숫자의 범위나 주어지는 숫자의 양 등, 너무 많은 문제의 경우 적용하기 힘들다.

## 로직
1. 고장난 버튼의 개수가 0인 경우 입력값을 받지 않으니 이 부분을 고려하자.
2. 최소값으로 숫자 버튼을 입력하는 것이 아닌, + 또는 - 버튼을 통해 이동할 때 얼마나 걸리는지 저장.
3. 반복문을 통해 0 ~ 100만까지의 채널을 눌러서 시작하는 경우를 다 확인.
4. 고장난 버튼으로 인해 누를 수 없는 채널인 경우 해당 반복은 패스.
5. 반복을 돌리면서 최소값을 계속 갱신하면 끝.

## 코드

```python
# https://www.acmicpc.net/problem/1107
import sys

# 버튼 횟수 찾기
def search(channel, broken_button):
    # 숫자를 안누르고 + 버튼으로만 이동하는 경우를 min값으로 설정해둔다.
    min_num = abs(100 - channel)

    # 0 ~ 1,000,000 까지 반복. 숫자의 범위가 100만인 이유는 원하는 채널의 범위는 50만이지만, 채널 자체는 무한하기 때문에 50만 이상의 채널에서 시작하는게 더 짧은 경우도 있다.
    for i in range(1000001):
        # 현재 체크하는 숫자에 고장난 버튼의 숫자가 포함되어 있는지 확인하기 위해 문자열로 변환.
        str_i = str(i)

        # 고장난 버튼의 숫자가 포함되어 있다면 break, 아니면 최소값 비교.
        for j in str_i:
            if int(j) in broken_button:
                break
        
        else:
            # i = 체크하려는 채널. abs()는 절대값 반환.
            # len(str_i) = 채널의 길이. 5432 채널이라고 치면 4개의 버튼을 눌러야 하니까 4를 +해줘야 한다.
            min_num = min((abs(i - channel) + len(str_i)), min_num)

    return min_num

input = sys.stdin.readline

channel = int(input())
str_channel = str(channel)
broken_button_num = int(input())

# 고장난 버튼이 없는 경우도 있음.
if broken_button_num == 0:
    broken_button = set()
else:
    broken_button = set(map(int, input().split()))

print(search(channel, broken_button))

```
