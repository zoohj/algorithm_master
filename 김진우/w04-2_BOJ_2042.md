## 문제 주소
* https://www.acmicpc.net/problem/2042

## 문제 설명
* N개의 수가 주어지고, 특정 수를 변경하는 명령과 특정 구간의 수들의 합을 구하는 명령이 주어짐.
* ex) 1 2 3 4 5 의 숫자가 주어지고, 3을 6으로 바꾸라는 명령과 2 ~ 5의 합을 구하라는 명령
* 값 변경 = 1 2 6 4 5, 합 구하기 = 2 + 6 + 4 + 5 = 17
* 주어지는 모든 명령을 수행하는 코드를 작성.

## 배운 내용
* 세그먼트 트리
* 세그먼트 트리는 여러 개의 데이터가 존재할 때 특정 구간의 합(최소값, 최대값, 곱 등)을 구하는 데 사용하는 자료구조

## 풀이 과정
* 처음에는 dp로 해결할까 싶었지만 값을 변경하는 처리를 하는 거에서 어려울 것 같아서 다른 방식을 찾아봄.
* 그래서 찾은게 세그먼트 트리.
* 세그먼트 트리 구현하고 입력값에 맞게 처리해주자.
* 세그먼트 트리의 특정 노드 수정하는 함수를 잘 보면 기존 노드의 값에 + 하는 방식으로 값을 변경함.
* 이러는 경우 내가 변경하려는 노드의 값이 3이고, 이걸 6으로 변경하기 위해서는 3을 더해줘야 한다.
* 그래서 변경하려는 값(6)에서 기존 값(3)을 빼주고 함수의 value에는 3을 넣어줘야 정상적으로 작동한다.
* 그리고 세그먼트 트리는 index 1부터 시작한다는 점을 주의!

## 로직
1. 입력값 받기
2. 값들 저장할 리스트와 트리, 정답용 리스트 3개를 생성하고 각각 초기화.
3. 트리 생성, 누적 합 구하기, 특정 값 변경하기 함수 구현
4. 반복문을 통해 주어지는 명령들 처리.

## 코드

```python
# https://www.acmicpc.net/problem/2042
import sys
# python 재귀 호출 제한 해제
sys.setrecursionlimit(10**7)
input = sys.stdin.readline

# 입력값 받기.
number_cnt, change_cnt, sum_cnt = map(int, input().split())

# 값들 저장, 트리 초기화, 정답 리스트 초기화
number_list = []
tree = [0] * (number_cnt * 4)
result = []

# 트리 생성
def tree_init(start, end, index):
    if start == end:
        tree[index] = number_list[start - 1]
        return tree[index]
    mid = (start + end) // 2

    tree[index] = tree_init(start, mid, index * 2) + tree_init(mid + 1, end, index * 2 + 1)
    return tree[index]

# 트리의 특정 구간 합 구하는 함수
def tree_sum(start, end, index, left, right):
    if left > end or right < start:
        return 0
    if left <= start and right >= end:
        return tree[index]
    
    mid = (start + end) // 2
    return tree_sum(start, mid, index * 2, left, right) + tree_sum(mid + 1, end, index * 2 + 1, left, right)

# 트리의 특정 노드 값 변경
def tree_update(start, end, index, node, value):
    if node < start or node > end:
        return
    
    tree[index] += value
    if start == end:
        return
    
    mid = (start + end) // 2
    tree_update(start, mid, index * 2, node, value)
    tree_update(mid + 1, end, index * 2 + 1, node, value)

# 숫자들 입력
for i in range(number_cnt):
    num = int(input())
    number_list.append(num)

# 트리 생성. 세그먼트 트리는 1번 인덱스부터 시작.
tree_init(1, number_cnt, 1)

# 명령들 입력 받기.
for i in range(change_cnt + sum_cnt):
    command, first_num, seconde_num = map(int, input().split())
    if command == 1:
        temp = seconde_num - number_list[first_num - 1]
        number_list[first_num - 1] = seconde_num
        tree_update(1, number_cnt, 1, first_num, temp)
    else:
        result.append(tree_sum(1, number_cnt, 1, first_num, seconde_num))

sys.stdout.write("\n".join(map(str, result)))


```
