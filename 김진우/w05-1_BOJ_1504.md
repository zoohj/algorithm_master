## 문제 주소
* https://www.acmicpc.net/problem/1504

## 문제 설명
* 1번 정점에서 N번 정점으로의 최단 경로를 구하려 하는데, 반드시 지나쳐야 하는 2개의 정점이 있다.
* 2개의 정점을 지나는 최단 경로를 구하자.

## 풀이 과정
* 1 -> a -> b -> end 이런 순서의 경로를 지나야 한다는 뜻.
* 최단 경로를 구해야 하니까 다익스트라를 사용. 1번 정점에서 다익스트라를 사용하고, a와 b 정점에서 다익스트라를 사용. 총 3번의 다익스트라 계산을 한 뒤에 값을 구할 수 있음.

## 로직
1. 시작점이 1인 다익스트라 실행.
2. 1 -> N의 경로가 있는지 확인. 없으면 -1 출력하고 끝.
3. a, b가 시작점인 다익스트라 각각 실행
4. 1 -> a -> b -> N의 경로와 1 -> b -> a -> N의 경로 둘 중 더 작은 값을 출력하면 끝!

## 코드

```python
# https://www.acmicpc.net/problem/1504
import sys
import heapq
from collections import defaultdict

def dijkstra(start, n, graph):
    dist = [float('inf')] * (n + 1)
    dist[start] = 0
    
    pq = [(0, start)]
    
    while pq:
        cost, now = heapq.heappop(pq)
        
        if cost > dist[now]:
            continue
        for w, nxt in graph[now]:
            new_cost = cost + w
            if new_cost < dist[nxt]:
                dist[nxt] = new_cost
                heapq.heappush(pq, (new_cost, nxt))
    
    return dist

input = sys.stdin.readline
graph = defaultdict(list)

# 입력값 받기.
vortex_num, edge_num = map(int, input().split())
for i in range(edge_num):
    vortex_a, vortex_b, edge_range = map(int, input().split())
    graph[vortex_a].append((edge_range, vortex_b))
    graph[vortex_b].append((edge_range, vortex_a))

target_vortex_u, target_vortex_v = map(int, input().split())

# 다익스트라 실행. 시작점이 1인 다익스트라의 결과를 dist_one에 저장.
dist_one = dijkstra(1, vortex_num, graph)

# 만약 1 -> vortex_num 까지의 경로가 없는 경우 -1을 출력.
if (dist_one[vortex_num] == float('inf')):
    print(-1)
else:
    # 시작점이 u, v인 다익스트라 결과 저장
    dist_u = dijkstra(target_vortex_u, vortex_num, graph)
    dist_v = dijkstra(target_vortex_v, vortex_num, graph)

    # 경로가 1 -> u -> v -> vortex_num인 것과, 1 -> v -> u -> vortex_num인 것 중 최소값 출력.
    one_u_v = dist_one[target_vortex_u] + dist_u[target_vortex_v] + dist_v[vortex_num]
    one_v_u = dist_one[target_vortex_v] + dist_v[target_vortex_u] + dist_u[vortex_num]

    print(min(one_u_v, one_v_u))

```
