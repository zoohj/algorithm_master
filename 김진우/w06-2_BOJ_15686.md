## 문제 주소
* https://www.acmicpc.net/problem/15686

## 문제 설명
* N x N 크기의 도시가 있는데, 도시에는 집, 치킨 집이 있다.
* 집과 가장 가까운 치킨 집 사이의 거리를 치킨 거리라고 함. 도시의 치킨 거리는 모든 집의 치킨 거리의 합이다.
* 치킨 거리의 공식은 |r1-r2| + |c1-c2| 이다.
* 도시에서 치킨 집을 폐업 시키려고 하는데, 도시의 치킨 거리가 최소값이 될 수 있도록 치킨 집을 폐업시켜야 한다.
* 폐업 시키지 않는 치킨 집을 최대 M개 골랐을 때, 도시의 치킨 거리의 최솟값을 구하자.

## 새로 배운 것
* combinations(list, num) 함수는 조합을 구하는 함수.
* list = [0, 1, 2]이고, num = 2라면, (0, 1), (0, 2), (1, 2) 이런식으로 조합을 구해준다.

## 풀이 과정
* 도시 정보 입력 받고 집이랑 치킨 집의 위치 저장
* 각 집마다 모든 치킨 집까지의 거리를 구해서 저장.
* 조합 함수를 통해 가능한 모든 치킨 집 조합을 구하고 도시의 치킨 거리를 비교. 가장 작은 값을 찾자.

## 로직
1. 입력 값 받고, 2중 반복문을 통해 집과 치킨 집 위치 저장.
2. 한번 더 2중 반복문 사용해서 이전에 구한 집과 치킨 집 위치를 통해 집 하나당 모든 치킨 집과의 거리를 저장.
3. 조합 함수를 사용해서 최대로 남겨둘 치킨 집의 조합을 모두 확인.
4. 구했던 조합들에 맞는 도시의 치킨 거리를 전부 구한다.
5. 조합이 (0, 1), (0, 2) 이런 식으로 되어 있다면, (0, 1)의 조합부터 테스트.
6. 치킨 집이 0번, 1번만 남아 있다고 가정. 각 집마다 구한 치킨 집의 거리를 통해서 집마다 최소 치킨 거리를 구하고 다 합치면 도시의 치킨 거리가 됨.
7. 이걸 반복해서 모든 조합을 돌아가며 도시의 치킨 거리를 계산하고 최소 값을 구하면 끝.

## 코드

```python
# https://www.acmicpc.net/problem/15686
import sys
from itertools import combinations

input = sys.stdin.readline

# 입력값 받기.
N, chicken_num = map(int, input().split())

# 도시 입력
arr = [list(map(int, input().split())) for _ in range(N)]

# 집이랑 치킨 집 위치 저장
home_list = []
chicken_list = []
for y in range(N):
    for x in range(N):
        if arr[y][x] == 1:
            home_list.append((y, x))
        elif arr[y][x] == 2:
            chicken_list.append((y, x))


# 각 집마다 모든 치킨 집의 거리 저장
chicken_len_list = []
for col, row in home_list:
    chicken_len = []
    for chi_col, chi_row in chicken_list:
        chicken_len.append(abs(col - chi_col) + abs(row - chi_row))
    
    chicken_len_list.append(chicken_len)

# 조합 함수를 사용해서 가능한 모든 치킨 집의 조합을 구한다.
# 이후 모든 조합에 대해 도시의 치킨 거리를 구하고 최소 값을 뽑는다.
min_value = float('inf')
for i in combinations(range(len(chicken_list)), chicken_num):
    
    # len_sum 변수에는 n번 조합의 도시의 치킨 거리를 저장.
    len_sum = 0
    # chi_lst에는 n번 집에서 모든 치킨 집까지의 거리가 저장되어 있음.
    for chi_lst in chicken_len_list:

        # n번 집에서 가장 가까운 치킨 집의 거리를 저장.
        temp_min = float('inf')
        for j in range(len(chi_lst)):
            # j가 i에 속해 있지 않다 = 현재 체크 중인 조합에 j번째 치킨 집이 없다는 뜻.
            # 현재 체크 중인 조합이 (0, 1, 2) 3개의 치킨 집 조합이면 3번 치킨 집은 계산하지 않는다.
            if j not in i:
                continue

            temp_min = min(chi_lst[j], temp_min)
        
        # n번 조합의 도시의 치킨 거리 구하기. n번의 가장 가까운 치킨 집 거리 추가.
        len_sum += temp_min
    
    # min 함수를 통해 모든 조합 중 가장 짧은 도시의 치킨 거리를 구한다.
    min_value = min(len_sum, min_value)

print(min_value)


```
