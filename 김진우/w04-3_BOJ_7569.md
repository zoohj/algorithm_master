## 문제 주소
* https://www.acmicpc.net/problem/7569

## 문제 설명
* 창고에 토마토가 보관되어 있음. 창고는 3차원 배열 형태
* 토마토는 익은 것과 익지 않은 것이 있다.
* 익지 않은 토마토는 주위에 익은 토마토가 있으면 하루 뒤에 익게 된다.
* 해당 토마토의 앞, 뒤, 좌, 우, 위, 아래에 있으면 주위에 있는 것.
* 토마토 외에도 토마토가 없는 빈 칸이 주어지는 경우도 있음.
* 창고의 모든 토마토가 익는 최소 시간을 구하자.
* 토마토가 다 익어 있으면 0. 다 익을 수 없으면 -1 출력.

## 배운 내용
* exit() 를 쓰면 프로그램 즉시 종료. 반복문 여러개 사용 중인데, 더 계산할 필요 없어질 때 사용함.

## 풀이 과정
* bfs 지만, 3차원 배열을 쓰는 문제.

## 로직
1. 입력값 받고 bfs 함수 구현
2. bfs에서 안 익은 토마토가 익은 토마토로 변할 때마다 값을 +1을 해줌. 이를 통해 창고의 모든 토마토가 다 익을 때까지 걸린 최소 시간을 구하는 것이 가능.
3. 반복문을 통해 bfs를 실행할 익은 토마토 위치를 전부 queue에 넣어주고 bfs 시작.
4. 마지막에 토마토를 하나 씩 확인해서 시간을 체크. 안 익은 토마토 나오면 바로 -1하고 종료.

## 코드

```python
# https://www.acmicpc.net/problem/7569
import sys
from collections import deque
input = sys.stdin.readline

# 입력값 받기.
row, col, height = map(int, input().split())

matrix = [[list(map(int, sys.stdin.readline().split())) for _ in range(col)] for _ in range(height)]
visited = [[[False]*row for _ in range(col)] for _ in range(height)]

# 왼쪽, 오른쪽, 앞, 뒤, 상, 하 이동을 위한 리스트
dr = [-1,1,0,0,0,0]
dc = [0,0,-1,1,0,0]
dh = [0,0,0,0,-1,1]

result = 0

queue = deque()

def bfs():
    while queue:
        cur_height, cur_col, cur_row  = queue.popleft()

        # 익은 토마토 주위에 안 익은 토마토가 있는지 확인
        for i in range(6):
            nr = cur_row + dr[i]
            nc = cur_col + dc[i]
            nh = cur_height + dh[i]

            # 상자 범위 밖으로 탐색하지 않도록 설정.
            if nr < 0 or nr >= row or nc < 0 or nc >= col or nh < 0 or nh >= height:
                continue

            if matrix[nh][nc][nr] == 0 and visited[nh][nc][nr] == False:
                queue.append((nh, nc, nr))
                matrix[nh][nc][nr] = matrix[cur_height][cur_col][cur_row] + 1
                visited[nh][nc][nr] = True

for z in range(height):
    for y in range(col):
        for x in range(row):
            if matrix[z][y][x] == 1 and visited[z][y][x] == False:
                queue.append((z, y, x))
                visited[z][y][x] = True

bfs()

for a in matrix:
    for b in a:
        for c in b:
            if c == 0:
                print(-1)
                exit(0)            
        result = max(result, max(b))

print(result - 1)


```
